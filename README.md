# HTML5 Semantic Structure & Accessibility — Internship Submission

## Project
Multi-page personal portfolio website built using semantic HTML5, CSS3 and vanilla JavaScript.

## Implemented requirements
- Semantic HTML5 elements: header, nav, main, section, article, aside, footer, address and form.
- Accessible skip link.
- Keyboard-friendly navigation and visible focus states.
- ARIA attributes only where they add useful accessibility information.
- Explicit labels for every form control.
- Required-field validation and live status messaging.
- Responsive mobile-first behavior.
- SEO-friendly titles and meta descriptions.
- Robots.txt and sitemap.xml.
- Reduced-motion support.
- Clean heading hierarchy.
