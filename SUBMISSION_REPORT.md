# Internship Work Submission Report

## Title
HTML5 Semantic Structure & Accessibility

## Objective
To build a multi-page personal portfolio website following modern semantic HTML5 standards and accessibility practices.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Work Completed
The project contains five connected pages: Home, About, Projects, Skills and Contact.

Semantic HTML5 landmarks were used to give the document a meaningful structure. Navigation includes a skip-to-content link and keyboard-visible focus states. The contact form uses explicit labels, appropriate input types, autocomplete attributes, required states and accessible status messaging.

SEO improvements include unique page titles, meta descriptions, robots directives, canonical metadata on the home page, descriptive page content and a sitemap.

## Accessibility Features
- Keyboard navigation
- Skip link
- Semantic landmarks
- Proper heading hierarchy
- Form labels
- Required-field validation
- Focus indicators
- ARIA live status
- Reduced-motion preference
- Responsive layout

## Expected Result
A clean, responsive and accessibility-focused portfolio that can be evaluated with Lighthouse Accessibility and SEO audits.

## Note
Lighthouse scores can vary depending on deployment, external assets, browser version and audit conditions. The implementation is structured to target high Accessibility and SEO scores.
